# Node.js_to_connect_MySQL

In this mini project, I'll show how to write "Node.js code to connect to and retrieve data from a MySQL database."

[1.] Prerequisites
Install Node.js on your computer.
Install an IDE on your computer. (you can use any other IDE or even Notepad).
Install a Database Management System (DBMS). In this tutorial, MySQL is used.

[2.] Grant access to the user
The next step is to grant access to the user for the database.
Let's say we have a user named Kim, and we want to grant Kim access to the database with the password Yeonkoung.
